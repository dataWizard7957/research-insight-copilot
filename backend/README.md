# Research Insight Copilot: backend API

FastAPI backend for [Research Insight Copilot](https://github.com/dataWizard7957/research-insight-copilot).
The web app is deployed separately; this Space only serves the API.

Required secret: `GROQ_API_KEY`. Optional variable: `ALLOWED_ORIGINS` (your frontend's URL).
